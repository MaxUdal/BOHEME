# Boheme и Armadi Art

Исходники интернет-магазина сантехники и мебели для ванной. Снимок опубликованной версии с обновлённым дизайном и разделом «Гарантия».

- `dist/` — витрина, базовый каталог, шрифты, изображения и видео из репозитория.
- `worker/` — API каталога, административная панель и скрипт сборки.

## Сборка

Выполните из корня проекта с Node.js 22 или новее.

```bash
node worker/build.mjs build
node --check build/index.js
```

Сборка создаёт Worker в `build/index.js`. Витрина использует серверные маршруты, в том числе `/api/catalog`, поэтому для запуска нужен Worker-совместимый хостинг. GitHub можно использовать для хранения исходников.

## Перенос данных

В архиве есть базовая выгрузка из репозитория. Изменения, внесённые через админку в действующее хранилище R2, и загруженные туда видео переносятся отдельно. Для админки на новом хостинге потребуется подключить хранилище `BUCKET`, задать `CATALOG_ADMIN_EMAIL` в настройках среды и настроить доверенную аутентификацию администратора. Текущая реализация использует заголовок аутентификации платформы Sites. На другой платформе его должна устанавливать проверенная система аутентификации, исключающая передачу этого заголовка от клиента.

Некоторые фотографии товаров и PDF-каталоги загружаются с сайта поставщика.
